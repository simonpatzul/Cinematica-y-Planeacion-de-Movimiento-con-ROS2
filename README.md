# Cinemática y Planeación de Movimiento con ROS2

Este repositorio contiene dos entregas académicas independientes, cada una en su propia carpeta con su propio README y sin mezclar resultados entre sí:

- **[KUKA_KR6_MATLAB/](KUKA_KR6_MATLAB/README.md)** — Taller IK: cinemática inversa analítica del KUKA KR-6 en MATLAB/Octave.
- **[UR5_MoveIt/](UR5_MoveIt/README.md)** — Taller UR5: ROS 2 Jazzy + MoveIt 2, planeación de movimiento y ciclo pick-and-place.

Entra a la carpeta correspondiente para ver el detalle, los requisitos y cómo ejecutar cada taller.
